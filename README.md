# Expense Tracker

## Overview
Expense Tracker is a simple web application built using HTML, CSS, and JavaScript. It helps users keep track of their income and expenses by calculating the current balance.

## Features
- Add income transactions
- Add expense transactions
- Automatically calculate the balance
- View transaction history
- Delete transactions
- Simple and responsive user interface

## Technologies Used
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Start adding your income and expense transactions.
